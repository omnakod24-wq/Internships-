# Week 4 — Complete Data Analysis

## Objective
Complete a small end-to-end data analysis project: load data, clean it, analyse it, create at least two chart types, and explain the findings in a written report.

## Tasks
1. Load the CSV from the `data/` folder.
2. Validate required columns and convert data types.
3. Handle missing values and duplicates.
4. Calculate summary statistics and group results by product and region.
5. Create at least two chart types and save them in `visualizations/`.
6. Write findings and limitations in `report/analysis_report.md`.
7. Use functions, comments, clear formatting, and error handling.

## Files
- `main.py` — complete analysis workflow
- `data/sales_data.csv` — sample sales dataset
- `visualizations/` — generated charts
- `report/analysis_report.md` — generated written insights
- `requirements.txt`

## Run
```bash
py -m pip install -r requirements.txt
py main.py
```

The dataset included here is a generated practice sample with 100 records and the columns Date, Product, Quantity, Price, Customer_ID, Region, and Total_Sales. It is not claimed to be the exact earlier inline file.
