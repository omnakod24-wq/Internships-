# Week 3 — Sales Data Analysis

## Objective
Use Python and pandas to load a sales CSV, inspect it, clean missing values and duplicate rows, calculate business metrics, and write a short report.

## Tasks
1. Load `sales_data.csv` with pandas.
2. Inspect the dataset shape, columns, and data types.
3. Handle missing values and remove duplicate records.
4. Calculate at least three metrics: total revenue, average sale, highest sale, lowest sale, and revenue by product.
5. Identify the best product by revenue.
6. Print and save a concise report with findings.

## Files
- `sales_analysis.py`
- `sales_data.csv`
- `analysis_report.md`
- `requirements.txt`
- `test_cases.txt`

## Run
```bash
py -m pip install -r requirements.txt
py sales_analysis.py
```

The included CSV is a sample dataset generated for practice. The script calculates results from the file rather than hard-coding expected totals.
